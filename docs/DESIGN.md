# 스타더스트 런 · 디자인 & 게임 기획서

확정된 컨셉: **A · 네온 우주 아케이드** (Claude 디자인 캔버스 "미니게임 컨셉 시안"의 첫 번째 시안)

## 한 줄 소개
작은 우주선이 별조각을 모으며 은하 중심까지 50개 섹터를 돌파하는 키보드 아케이드 게임.

## 비주얼

### 색상 토큰
| 이름 | 값 | 용도 |
|---|---|---|
| space-deep | `#07021a` | 가장 바깥 배경 |
| space-mid | `#120634` | 배경 중간 |
| nebula-violet | `#2a1160` | 성운 중심 |
| ink | `#f1ecff` | 기본 글자 |
| ink-muted | `#b9a8f0` | 보조 글자, 라벨 |
| cyan | `#7ef6e4` | 플레이어, 주요 강조 |
| pink | `#ff5cbe` | 위험, 적 계열 |
| gold | `#ffe27a` | 별조각(수집물), 최고 점수 |
| orange | `#ff8a3d` | 블랙홀, 항성대 |

### 폰트 (Google Fonts)
- **Orbit**: 한글 제목과 본문 전체
- **Chakra Petch** (500, 700): 숫자, 영문 라벨, HUD (SCORE, SECTOR 등)
- Inter, Pretendard, Noto Sans 같은 흔한 고딕은 쓰지 않는다.

### 화면 구성
- 배경: 보라·분홍·청록 성운 radial gradient + 반짝이는 별 + 큰 행성 실루엣
- HUD: 테두리 있는 알약형 박스 (SECTOR 12 / 50, SCORE, BEST), Chakra Petch
- 하단 패널: 반투명 남색 박스, 얇은 보라 테두리
- 제목에는 분홍 네온 글로우 (`text-shadow: 0 0 24px rgba(255,92,190,.65)`)
- 화면이 어두워지는 연출은 쓰지 않는다. 구역이 바뀌면 성운 색이 바뀐다.

## 구역 (10스테이지씩 5구역)
| 스테이지 | 구역 | 대표 색 | 새로 등장하는 몬스터 |
|---|---|---|---|
| 1–10 | 보라 성운 | `#5a2fd0` | 운석, UFO |
| 11–20 | 청록 성운 | `#1fb5a8` | 레이저 위성, 혜성 |
| 21–30 | 항성대 | `#ff8a3d` | 블랙홀, 태양 플레어 |
| 31–40 | 분홍 은하 | `#ff5cbe` | 분열 슬라임 외계인, 추적 드론 |
| 41–50 | 금빛 코어 | `#ffe27a` | 모든 몬스터 혼합 + 강화형 |

- 10, 20, 30, 40, 50스테이지는 **보스 스테이지** (예: 모선 UFO, 거대 블랙홀)
- 스테이지가 오를수록 별조각 수, 적 수, 적 속도, 에너지 감소 속도가 조금씩 증가

## 몬스터
| 이름 | 행동 |
|---|---|
| 운석 | 직선으로 날아와 화면 밖으로 사라짐 |
| UFO | 지그재그로 이동 |
| 레이저 위성 | 제자리에서 주기적으로 빔 발사 (발사 전 예고선 표시) |
| 혜성 | 플레이어 방향으로 빠르게 돌진 |
| 블랙홀 | 주변의 플레이어를 끌어당김, 중심에 닿으면 피해 |
| 태양 플레어 | 화면 가장자리에서 경고 후 불기둥 |
| 분열 슬라임 외계인 | 대시로 맞히면 둘로 나뉨 |
| 추적 드론 | 느리게 계속 따라옴 |

## 조작 (기존 유지)
- 방향키 또는 WASD 이동, Space 대시(잠깐 무적), P/Esc 일시정지·재개, Enter 시작·다음, R 스테이지 다시, H 플레이 방법
- 한글 입력 상태에서도 작동하도록 `e.code` 사용

## 랭킹
- 게임 오버 또는 50스테이지 클리어 시 이름(최대 8자) 입력
- 브라우저 localStorage에 **Top 10** 저장 (점수, 도달 스테이지, 날짜)
- 타이틀 화면과 헤더에 개인 최고 점수 표시
- 랭킹 보기 버튼 (단축키 L)

## 플레이 방법 모달 (기존 유지, 내용만 새 컨셉으로)
그림이 들어간 단계별 설명: 목표 → 이동 → 에너지 → 몬스터 도감 → 대시·일시정지 → 점수·랭킹
